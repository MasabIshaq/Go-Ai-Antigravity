# Download Site Structure

Place your built app files inside this `files/` folder:

| File | What to put here |
|------|-----------------|
| `Go-Ai-Setup-1.0.0.exe` | The Windows EXE installer (from GitHub Actions > Windows-EXE artifact) |
| `go-ai_1.0.0_amd64.deb` | The Linux DEB package (from GitHub Actions > Linux-DEB artifact) |
| `go-ai-v1.0.0.apk` | The Android APK (from GitHub Actions > Android-APK artifact) |

Once you place the files here, they will be instantly downloadable from the website.
